# 自动审查

[English](auto-review.md) | 中文

Auto-review 为符合条件的普通文件操作提供建议；审批策略、沙箱和执行权限仍由 Host 管理。功能默认关闭。已注册的 Codex 账号路由使用各自捕获的账号完成整次审核请求；绑定不可用时不会改用其它账号。

## 本地授权

启用 Auto-review 仍须通过已有 profile 告知。另行选择 `autoReviewLocalPolicy`：`manual` 不授予常驻文件权限，`workspace-read` 允许符合条件的普通文件读取，`workspace-files` 还允许原工作区内有界的普通文件写入。远端 allow 不能创建这些权限。已有 profile 即便先前开启了审核器，也默认采用 manual。

预检从 Agent 当前的文件系统和工作目录服务读取元数据，不使用 Host 进程目录代替。它要求能确认是 Host 本地执行世界、规范化目标仍在原工作区内、目标为普通非链接文件且参数无歧义。敏感凭据、安全与 Agent 配置文件、Shell、递归搜索和不支持的操作仍交人工确认。Windows 编辑器路径必须完整限定驱动器。最终复查降低陈旧目标风险，但不能消除之后的文件系统竞态。

## 决策与精确重试

- 远端评为高/极高风险、授权不足或未知、元数据不可用、凭据缺失、响应畸形和传输失败均不能放行执行。
- 结构化 deny 会拒绝动作，注入经敏感信息过滤的理由和禁止绕行指引。同一轮连续拒绝三次，或最近五十次中拒绝十次，会停止该轮。
- 超时只允许再审核同一动作一次，不授权执行。取消和插件卸载会阻止晚到决策；账号命令会撤销待处理重试并取消在途审核。
- `/approve <完整拒绝记录 ID>` 必须经真实人工命令接口，只能批准一次本地符合条件的精确重试，且命令记录须成功结束。工具、参数、提供方、实际目录、本地范围和目标观察值必须仍相同。敏感或高风险动作不能使用此覆盖；不匹配或停用期间经过另一审批边界会消费/撤销授权。
- 命令记录插件通知，不伪造人工 follow-up。须经正常会话/工具接口继续或重试；命令本身不启动模型轮次。

原生工具调用与当前 PTC 启动记录提供动作证据。缺失、重复或不匹配的派发证据会转人工。审批和命令生命周期仍由 Harness 记录；本集成不重写会话历史，也不添加插件私有的必读事件。

## 告知与限制

审核请求会把有界的最近会话文本、相关工具证据、参数和计划动作发送到 `chatgpt.com`。已保存凭据只用于正常认证；隐藏推理不作为审核上下文。尽力脱敏不是完整的秘密检测器。保留的完整人工文本只是证据，不是本地授权。

输入上限为：会话文本 20,000 UTF-8 字节、工具上下文 10,000 字节、单条文本 5,000 字节、单条工具记录 1,000 字节，以及四十条最近非用户记录。请求包含省略和截断事实。OpenAI 未承诺隐藏审核器的 OAuth 路由是稳定公共 API；合成检查不能证明真实账号可用。参见[本地集成参考](local-feature-update.zh.md)与 [OpenAI Auto-review](https://learn.chatgpt.com/docs/sandboxing/auto-review)。
